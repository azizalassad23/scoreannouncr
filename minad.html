Buka halaman siswa

Atur sumber data dan upload GIF + suara untuk tiap tier. Tombol Simpan & Publikasikan mengirim file langsung ke repo GitHub kamu. Halaman siswa ter-update sekitar 1 menit kemudian.

1

Koneksi GitHub

Butuh fine-grained personal access token dengan izin Contents: Read and write untuk repo ini saja. Cara membuatnya ada di README.

Belum terhubung.

2

Data Google Sheets

Di Google Sheets: File › Bagikan › Publikasikan ke web, pilih sheet nilai, format CSV, lalu tempel link-nya di sini. Kosongkan untuk mode demo.

Isi hanya jika sheet tidak punya kolom Mapel. Urutan nama mengikuti urutan baris tiap siswa.

3

GIF & suara per tier

GIF: gif, webp, png, jpg. Suara: mp3, wav, ogg, m4a. Maksimal 20 MB per file. Tier tanpa suara memakai nada bawaan.

Hubungkan GitHub dulu untuk menyimpan.

    4

    QR code untuk siswa

    Cetak dan tempel QR ini. Siswa cukup scan untuk membuka halaman nilai. Gambar tengah tidak di-upload ke mana pun; semuanya dibuat di browser ini.
